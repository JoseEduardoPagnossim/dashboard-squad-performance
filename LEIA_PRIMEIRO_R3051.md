# R30.5.1 — Painel de notas baixas compacto

Use este pacote sobre a R30.4 publicada (ou R30.5 se já foi aplicada).

O ZIP incremental tem `index.html`, `package.json`, `css/styles.css`, `js/app.js` e os arquivos de testes com suas **pastas corretas**, sem uma pasta extra do projeto. Copie o conteúdo do ZIP para a raiz do repositório existente, substituindo os arquivos de mesmo nome. Preserve sua pasta `.git`.

Para evitar cache incorreto, a revisão dos assets é `2.63.9-r3051`.

Depois de copiar, execute `npm run check`, faça o commit e o push; confirme o Actions e atualize a página com Ctrl+Shift+R.

Não há SQL ou migration. A UI mudou de posição e apresentação, sem alterar dados nem cálculos.
