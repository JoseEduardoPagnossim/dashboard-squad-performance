# Filtros estaveis - V2.34.3

A versao 2.34.3 padroniza os controles do cabecalho e do painel Indicadores.

## Objetivo
Evitar que filtros mudem de largura ou altura quando o usuario troca Squad, mes, tecnico, periodo ou opcao ativa.

## Ajustes
- larguras reservadas no desktop;
- altura unica para os controles do topo;
- texto com ellipsis sem alterar a caixa externa;
- datas com largura fixa e numeros tabulares;
- atalhos de periodo em grade estavel;
- usuario e botao de tema com dimensoes fixas;
- filtros dos Indicadores em grade previsivel;
- reorganizacao responsiva em 1450, 980, 720 e 480 px.

Nenhum calculo, permissao ou fonte de dados foi alterado.
