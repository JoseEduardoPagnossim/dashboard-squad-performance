# Publicação no GitHub Pages

O frontend não requer build. O GitHub Pages pode publicar diretamente a raiz da branch configurada.

## Endereço atual

```text
https://joseeduardopagnossim.github.io/dashboard-squad-performance/
```

## Arquivos necessários

A publicação deve conter, no mínimo:

```text
index.html
assets/
css/
js/
```

Os caminhos usados pela aplicação são relativos ao `index.html`, portanto a troca do nome antigo do repositório não exige `base` de Vite/React.

## Após publicar

1. abra a URL em janela anônima;
2. confirme carregamento de CSS, favicon e imagens;
3. valide o login;
4. confira o Console/Network do navegador para erros 404;
5. teste ao menos uma tela de cada perfil de acesso.
