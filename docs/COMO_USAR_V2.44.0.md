# Como usar — V2.44.0

A V2.44.0 não muda o fluxo de trabalho do Performance Hub. Ela padroniza visualmente a interface para facilitar a leitura dos módulos existentes.

## Como interpretar a interface

- **Cards de KPI:** mostram a informação que deve ser lida primeiro, como realizado, meta, projeção, avaliação e valores.
- **Cards de análise:** concentram gráficos, rankings, histórico e comparações.
- **Cards de configuração:** identificam áreas em que o Administrador altera regras ou comportamento do sistema.
- **Chips e badges:** representam status, competência, risco, perfil ou contexto.
- **Tabelas:** cabeçalhos permanecem visíveis durante a rolagem. Em tabelas largas, a primeira coluna permanece fixa para preservar a identificação da linha.

## Tabelas largas

Quando houver muitas colunas, use a rolagem horizontal do próprio bloco da tabela. A primeira coluna permanece visível nas tabelas classificadas como largas. Tabelas com muitas métricas usam densidade visual menor automaticamente.

## Densidade do painel

A preferência de layout existente continua disponível em Configurações. Ao escolher o modo compacto, cards e tabelas também passam a usar menos espaço vertical.

## Temas

O Design System respeita as cores definidas pelo tema do Squad. A padronização não substitui tema, imagem, favicon ou preferências de gráficos.

## Perfis

A V2.44 mantém o modelo atual:

- Administrador: acesso integral;
- Técnico: acesso operacional conforme permissões.

Não há migration nova nesta versão.
