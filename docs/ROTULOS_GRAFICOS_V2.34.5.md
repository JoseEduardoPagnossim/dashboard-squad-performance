# V2.34.5 — Rótulos de dados nos gráficos

Todos os gráficos SVG do dashboard passam a exibir os valores diretamente na tela, mantendo o tooltip por hover como recurso complementar.

## Cobertura

- Produção diária do técnico.
- Histórico de atendimentos.
- Indicadores por Squad e organização.
- Comparativos de técnicos em tela cheia.
- Indicadores de qualidade: atendimentos x avaliação e distribuição das notas.
- Séries percentuais e monetárias, respeitando os formatadores existentes.

## Legibilidade

Os rótulos usam contorno baseado no painel, tamanho compacto e deslocamento alternado entre séries para reduzir colisões. Em telas menores o tamanho da fonte é reduzido automaticamente.
