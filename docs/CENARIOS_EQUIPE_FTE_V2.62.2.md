# V2.62.2 — Simulação de equipe e FTE

As premissas de quantidade de pessoas são agregadas. FTE é equivalente de jornada, não contagem de pessoas. Para jornadas heterogêneas, os resultados são aproximações e dependem de validação operacional. A referência padrão é 44 horas/semana, ajustável no motor; a UI trabalha com a referência padrão. Transferências são neutras no total de todos os Squads. Não há escrita no banco.
